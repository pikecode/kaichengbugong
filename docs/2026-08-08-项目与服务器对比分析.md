## 一、项目整体架构

本项目为**开成不公电商溯源系统**，采用前后端分离架构：

| 层级 | 技术栈 | 位置 |
|------|--------|------|
| 前端 | UniApp + Vue.js + uView UI | 本地 `cwlsuniapp/` |
| 后端 | FastAdmin + ThinkPHP 5.0.24 | 仅服务器 `/www/wwwroot/cwls.turuifanxin.cn/` |
| 数据库 | MySQL 5.7（cwls库，fa_ 前缀，约63张表） | 服务器本地 |
| 部署工具 | sshpass + scp 手动脚本（`docs/deploy-backend.sh`） | — |

## 四、关键风险项

### 🔴 高优先级

| 风险 | 说明 | 建议 |
|------|------|------|
| SSL 证书 7 天后过期 | 2026-08-15 到期，无自动续签 | 立即续签并配置 cron |
| 后端无版本控制 | 服务器代码与本地无 git 同步，改动难追踪 | 建议引入 git 管理或 CI/CD |

## 五、部署流程现状

目前部署流程为**全手动**：

```
本地修改代码
    ↓
执行 docs/deploy-backend.sh（sshpass + scp 上传指定文件）
    ↓
服务器自动清理 runtime 缓存
    ↓
手动验证
```

**问题：** 每次只上传脚本中指定的几个文件，不是全量同步，容易遗漏。
