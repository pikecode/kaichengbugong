## 五、核心业务流程

### 用户购物流程

```
首页浏览商品 → 商品详情 → 加入购物车 → 提交订单
→ 选择地址/优惠券 → 收银台 → 微信/支付宝支付
→ 等待发货 → 确认收货 → 评价
```

### 溯源/配料回放流程

```
首页"核心配料全程回放"板块
    → packageC/index/plhf（配料全程回放页）
        → packageC/ingredientreplay/items（回放项目）
            → packageC/ingredientreplay/videos（视频播放）

商品详情页
    → 溯源视频入口
        → packageC/index/sycp（溯源产品）
            → packageC/index/sycpvideo（溯源视频）
```
